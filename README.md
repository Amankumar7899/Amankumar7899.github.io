## About

This repository contains my personal portfolio website. The site presents my background, projects, technical skills, education, certifications, and contact details in a custom dark interface inspired by modern cinematic product/developer experiences.

The portfolio is intentionally built as a lightweight static site without a frontend framework or backend server.

## Highlights

- Cinematic boot/loading sequence

- Responsive layout for desktop, tablet, and mobile
- 3D/parallax profile card with my professional portrait
- Floating technical HUD labels and status panel
- Scroll-reveal animations
- Interactive project detail modals
- Reduced-motion support
- Contact form that opens the visitor's default email client
